Image file tips

An extension is only a hint. ImageWalker also examines the file header, so a correctly encoded image can often be opened after it has been given the wrong extension.

If a file will not open, confirm that it is one of the supported formats, try another known viewer, and copy the file from removable or network storage before trying again. A zero-length, partially downloaded or damaged file cannot be recovered by changing its name.

JPEG uses lossy compression; repeated Save operations reduce quality. PNG, TIFF and BMP can retain exact pixels, although format conversion cannot restore detail already discarded by JPEG.
