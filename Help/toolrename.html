Renaming files

Select one or more files and choose File > Rename. The dialog lists every proposed destination before any file is moved.

Enter a literal name for one file. For a series, a run of number signs inserts the sequence number and a question mark inserts the current base name. Adjust the starting number until the preview is correct, then confirm the operation.

ImageWalker uses temporary names when destinations overlap. If any move fails, it restores every name it can without overwriting another file and reports any temporary name which remains.
