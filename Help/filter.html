Editing images

Select an image and choose View > Edit or Image > Edit. The edit panel applies a non-destructive sequence while the original file remains unchanged.

Geometry

Rotate, straighten, correct perspective and drag the crop rectangle on the image. Auto Straighten estimates the horizon. Reset Crop restores the full edited image.

Colour

Adjust brightness, contrast, darks, midtones, lights, saturation, vibrance, temperature and tint. Auto Colour chooses tone values from the image. Compare Before and After temporarily shows the source image.

Saving

Save replaces the current file only after an edit. Save and Move Next saves and advances; Save As writes a new file. Discard Changes returns to the unedited image. Undo Image Edit restores the preceding edit state.

Rotate Left and Rotate Right in the item view operate directly on selected files and preserve JPEG image data without re-compression.
