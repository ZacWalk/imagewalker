Support

ImageWalker writes a log beside its executable. The file name matches the application, for example imagewalker23.log or imagewalker23d.log. A serious failure can also create a dump and matching diagnostic information.

Report a problem on GitHub Issues. Include the ImageWalker version, the action which triggered it, and whether it happens with a particular file. Check logs for private paths or filenames before attaching them. Keep an original copy of any file that reproduces an image-loading or saving problem.

The ImageWalker repository contains the source code and build instructions.
