Support

ImageWalker writes a log beside its executable. The file name matches the application, for example imagewalker23.log or imagewalker23d.log. A serious failure can also create a dump and matching diagnostic information.

When reporting a problem, include the ImageWalker version, the action which triggered it, whether it happens with one particular image, and the relevant log. Keep an original copy of any file which reproduces an image-loading or saving problem.

Project information is available from the ImageWalker home-page command on the Help menu.
