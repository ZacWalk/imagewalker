Supported image formats

All releases use the same image engine. The built-in readers cover the formats below; each application keeps its own viewing, editing and file-workflow commands. ArtMate remains read-only.

FormatCommon extensions
JPEGjpg, jpeg, jpe
Windows bitmapbmp, dib
GIFgif
PNGpng
TIFFtif, tiff
Static WebPwebp
Photoshoppsd
WordPerfect graphicswpg
PC Paintbrushpcx
Windows metafilewmf, emf
Compound-document previewspps, ppt, vsd

Additional formats, including some RAW and HEIF files, depend on the Windows image codecs installed on the computer. WebP support is bundled and needs no separate Windows codec. Document previews are not editable photographs.

Animated WebP is not supported. WebP orientation and metadata are not carried by the current WebP reader and writer. Use a format that can preserve the information required by your workflow.

Save As and Convert Images show only formats and options which can be written by the selected operation. See image file tips when a recognised file does not open.
