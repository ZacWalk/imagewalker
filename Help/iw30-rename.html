Batch Rename

Select files and press Ctrl+Shift+R or choose Batch Rename to make copies with new names. Originals stay where they are. A run of # characters is a zero-padded sequence number; {token} substitutes metadata. Review shows the complete new names, including extensions and companion files.

Invalid names, duplicate destinations and unresolved collisions block Run. Changing the template, start number or collision policy generates a new plan. Use F2 to rename a single file or folder in place without replacing another item.

Cancel leaves completed copies in place. Read the results before retrying a partial run.
