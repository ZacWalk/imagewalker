Using ImageWalker

The item pane shows the current folder; the image pane shows the focused image or a collage of the selection. Use the address bar, folder history and Browse Parent command to move between folders.

Modes

ModePurpose
NormalBrowse and view the current folder.
FoldersChoose a folder beside the normal item and image panes.
SearchFind matching images and work with the results.
EditCrop, straighten and adjust the current image.
PrintPreview printed pages and contact sheets.

Item views

Choose Thumbnail, Detail or Matrix from the View menu. Arrange Icons sorts by name, size, type, modified date, date taken or another image property. The Options dialog controls thumbnail annotations and detail columns.

Viewing

Use Previous Image and Next Image to step through a folder. Scale commands fit, fill or display the image at a fixed percentage. Full Screen hides the surrounding controls until you leave it.

Files

The File and Edit menus open, copy, move, paste, rename, recycle or show properties for selected files. Open in Windows Explorer reveals the focused item. Copy File Paths places one full path per line on the clipboard.
