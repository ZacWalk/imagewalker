Open with

Select files, then use the Open menu or Ctrl+Enter for the searchable chooser. Windows applications are marked (app); configured and internal commands are marked (tool). Frequently used entries appear first.

Registered Windows applications require files of one type. Configured batch tools can receive mixed types when their declarations accept every selected file.

Configured tools are read from imagewalker30-tools.json beside the executable. The tools object contains absolute search folders and apps with exe, invoke, extensions, optional group, and text fields. The executable must be discovered within the search folders; arbitrary command paths are not run.

Begin invoke with {exe-path}. Use {item-path} for one file or {item-paths} for all selected files. Paths are quoted individually. A one-file declaration retains its old behavior and is explicitly labelled first item only.

Use Help > Tool configuration to inspect missing files, invalid declarations and executables that could not be found. Correct the configuration and restart to discover it again.

Changes made by external applications are outside ImageWalker's results and recovery history.
