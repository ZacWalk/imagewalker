ImageWalker versions

The historical versions are updated to build and run on modern 64-bit Windows. These are the highlights introduced by each release.

VersionYearNew features
ArtMate 1.01998Read-only thumbnail browsing and image viewing
ImageWalker 2.02001Descriptions, print preview and slide shows
ImageWalker 2.22003Compare and Print modes, Filters and Actions views, six batch tools
ImageWalker 2.32006Image tagging, EXIF auto-rotation and the Resize Images wizard
ImageWalker 3.02026Video and audio playback, reviewed file workflows and folder synchronization

In ImageWalker 2.3, use the Metadata command to inspect the loaded image.

Some historical features, including slide shows, Compare mode, and the Filters and Actions views, are unavailable in the x64 editions. The other help topics describe how to use the available commands.
