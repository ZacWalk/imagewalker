ImageWalker versions

The collection includes five standalone applications, in 32-bit and 64-bit editions. These are the features you can use in each rebuilt release.

VersionYearHighlights
ImageWalker 1.01998Read-only thumbnail browsing and image viewing
ImageWalker 2.02001Descriptions, print preview and image editing
ImageWalker 2.22003Vertical mode bar, Favourites and Print mode
ImageWalker 2.32006Dark interface, image tagging, EXIF auto-rotation and a Metadata command
ImageWalker 3.02026Video and audio playback, reviewed file workflows and folder synchronization

In ImageWalker 2.3, use the Metadata command to inspect the loaded image.

Some historical features, including slide shows, Compare mode, and the Filters and Actions views, are unavailable in the rebuilt editions. The other help topics describe how to use the available commands.
