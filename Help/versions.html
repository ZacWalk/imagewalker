ImageWalker versions

ImageWalker 2.0, 2.2 and 2.3 use the same commands, modes, tools, options and image formats. They differ mainly in presentation.

VersionPresentation
2.02001 wordmark, tab selector and framed panes
2.22003 wordmark, vertical mode bar and framed panes
2.32006 toolbar mode buttons, borderless panes and dark colours

Where one command differs, the relevant topic says so. ImageWalker 2.3 adds the Metadata command to inspect the loaded image.

ArtMate 1.0 is the read-only predecessor.
