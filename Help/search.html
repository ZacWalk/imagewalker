Finding images

Choose Search mode or a command from File > Search. Search Current Folder starts with the folder being viewed; Search My Pictures starts at the Windows Pictures folder. Images in sub folders controls recursive searching.

The Advanced Search panel can match file names, dates, sizes and available image properties. Keyword expressions accept AND, OR and NOT; plus and minus can be used as short forms for required and excluded terms.

Results appear in the normal item pane, where they can be viewed, selected and processed like folder items. Search Clear returns to ordinary browsing.
