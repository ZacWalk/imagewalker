Convert and Resize

Select photos, open Convert, and choose a destination, output format and collision policy. Review shows each proposed output. Run is disabled until the plan is valid; the status explains any unresolved problem.

Quality applies to lossy encoders. A maximum dimension scales down without enlarging smaller photos. Static WebP is bundled and supports lossy or lossless output with alpha. Originals are kept, and a source is never its own output.

Block run refuses occupied destinations, Skip preserves them, Auto-rename chooses a free name in Review, and Replace explicitly replaces them. Changing a destination or format requires a new plan.

Cancel leaves completed outputs in place. Inspect row outcomes before running again.
