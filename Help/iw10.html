ImageWalker 1.0

ImageWalker 1.0 is the original read-only release. It browses shell folders as thumbnails or details and displays the selection in an image pane. Photos are shown as stored, without turning them to the camera's orientation.

Paste a folder path into the address box and press Enter to open it. The bottom bar puts the zoom and image controls first, then the selected image's name, dimensions, pixel format and file size. The item counts sit beside the thumbnail size slider at the right. Drag that slider to resize the centered thumbnail grid. It does not change the image preview zoom. Scrollbars appear in the image pane only when the image needs panning. The image pane supports copying and a collage for multiple selected images. It does not rename, delete, edit, convert, search or print files.

Full screen

Focus a photo and press Enter or F11 to view it full screen. Enter or Space goes to the next photo; Left and Right step between photos when Fit is active. Press Z to see the actual size and drag or use the arrow keys to pan. Escape cancels a drag or returns to Fit before leaving fullscreen. F11 or the Full screen command in the right-click menu returns directly to the windowed layout. Alt+Left and Alt+Right go Back and Forward; Alt+Up opens the parent folder.
