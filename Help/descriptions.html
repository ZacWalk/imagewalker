Descriptions and metadata

The Description Panel and image-detail commands display information stored with the focused image, including available EXIF, IPTC and XMP fields. Options can show descriptions in Detail view and markers on thumbnails which contain EXIF, ICC or IPTC data.

Descriptions and dates can be used as thumbnail annotations, detail columns, search properties and contact-sheet captions.

ImageWalker 2.3 also has Image > Metadata, a read-only viewer for the loaded image's information. Opening or closing it does not change the image or enable Save.

Metadata which ImageWalker does not interpret is retained when an image is saved. Camera orientation is changed only when the stored pixels are actually reoriented.
