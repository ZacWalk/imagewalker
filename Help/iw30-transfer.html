Copy and Move

Select files and press Ctrl+Shift+C to copy or Ctrl+Shift+X to move. The dialog previews the selection, total size and destination folder. Existing .xmp, .thm and .aae companions travel with their primary file.

Auto-rename is the default when a destination exists. Replace is an explicit choice for the entire file-and-sidecar set. Check the destination before confirming: a move removes the source after that row succeeds.

The operation runs to completion; it has no Cancel button. A failed row does not hide earlier results. Reopen Last Copy/Move results from the file context menu to inspect the outcome.
