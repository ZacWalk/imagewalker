Processing several images

The Tools menu provides three batch operations:

  • Convert Images writes another image format.
  • Resize Images changes pixel dimensions.
  • Loss-Less JPEG rotates, mirrors or optimises JPEG files.

Each tool selects the current items or folder, can follow subfolders and writes results to a destination folder. Existing results receive a unique name; the source file is never accepted as the output file. A file becomes visible at its destination only after processing completes successfully.

Rename is a direct file command rather than a batch tool. Contact sheets are created from Print mode.
