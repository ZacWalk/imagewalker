ImageWalker 3.0

Choose Browse to view the current folder. The mode strip opens Convert, Rename, Edit and Sync; pressing an active mode returns to Browse. Folders toggles the folder tree, and Full screen hides the browsing chrome.

File workflows

  • Open with an application or configured tool
  • Copy or move files and sidecars
  • Convert or resize images
  • Batch rename
  • Photo Edit
  • Synchronize folders

Convert, Rename and Sync require a reviewed plan. Analyze reads the sources, Review lists every proposed action, and Run performs that snapshot. Changing targets or destinations discards the old plan. A destination appearing after Review is never silently overwritten.

Cancel stops future rows, not completed work. Inspect the Success, Failed, Skipped and Not run outcomes before repeating a batch. Closing a busy task asks whether to cancel; Close returns to Browse, not Exit.

Settings and the latest-run diagnostic log are kept beside the executable. The Debug executable has separate settings and log files.

Double-click a video or audio file, or press Enter, to open its playback task. A single selection previews its poster and properties. Play/Pause, Stop, seek and volume use the installed Windows media components; unavailable components are reported without disabling image browsing.

Undo and recovery

Edit > Undo (Ctrl+Z) undoes a Photo Edit draft, or the latest completed file task after the task view is closed. File Undo asks for confirmation and refuses externally changed files. It covers Convert, Rename, Sync, the Copy/Move dialog and Photo Edit saves; Windows shell clipboard/drop and Recycle Bin actions use Windows recovery instead.

Automatic Undo lasts for the current session. Original bytes and recovery manifests remain in imagewalker30.undo beside the executable after exit or a crash, but are not replayed automatically or removed automatically. Keep these copies until you no longer need recovery.
