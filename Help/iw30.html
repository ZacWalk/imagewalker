ImageWalker 3.0

Choose Browse to view the current folder. The mode strip opens Convert, Rename, Edit and Sync and hides while a task is open. Close or Escape returns to Browse, with a prompt if a draft or an operation is still active. Folders toggles the folder tree.

Hover over a toolbar icon to read its command in the status bar. Click a folder in the path next to the toolbar to return to it, or click its chevron (>) to choose a subfolder. When the path is too wide, the ellipsis opens the earlier folders. Fit and Zoom are in the status bar alongside the thumbnail size slider.

Enter opens the focused folder or shows a photo full screen. F11 toggles full screen; once there, Enter advances to the next photo. Drag the size slider above the filmstrip to resize thumbnails. The arrow shows or hides the filmstrip. Blue ticks on its scrollbar show where the selected photos are in the folder. Alt+Left and Alt+Right go Back and Forward; Alt+Up opens the parent folder.

Photos are shown upright, following the orientation the camera recorded.

ImageWalker follows the Windows app colour setting, using a dark palette in Dark mode and a light palette in Light mode. Windows contrast themes take priority.

File workflows

  • Open with an application or configured tool
  • Copy or move files and sidecars
  • Convert or resize images
  • Batch rename
  • Edit photos, video and audio
  • Synchronize folders

Convert, Rename and Sync require a reviewed plan. Analyze reads the sources, Review lists every proposed action, and Run performs that snapshot. Changing targets or destinations discards the old plan. A destination appearing after Review is never silently overwritten.

Cancel stops future rows, not completed work. Inspect the Success, Failed, Skipped and Not run outcomes before repeating a batch. Closing a busy task asks whether to cancel; Close returns to Browse, not Exit.

Settings and the latest-run diagnostic log are kept beside the executable. The Debug executable has separate settings and log files.

Double-click a video or audio file, or press Enter or Space, to play it in Browse without leaving the item list. Space plays or pauses; F7 mutes or unmutes. Choose Sound to set the playback volume, or use the timeline to seek. Escape stops playback and returns to the poster; selecting another item also stops playback. If Photos Only is on, turn it off to browse for audio and video.

ImageWalker has built-in decoders for common formats such as H.264 and HEVC video, VP8 and VP9, MP3, AAC, FLAC and Opus. It uses Windows playback codecs as a fallback where available. To hear sound, select an enabled Windows audio output.

Undo and recovery

Edit > Undo (Ctrl+Z) undoes a photo or media edit draft, or the latest completed file task after the task view is closed. File Undo asks for confirmation and refuses externally changed files. It covers Convert, Rename, Sync, the Copy/Move dialog and Edit saves; Windows shell clipboard/drop and Recycle Bin actions use Windows recovery instead.

Automatic Undo lasts for the current session. Original bytes and recovery manifests remain in imagewalker30.undo beside the executable after exit or a crash, but are not replayed automatically or removed automatically. Keep these copies until you no longer need recovery.
