Printing images

Choose View > Print or Print > Print to enter Print mode. The preview shows the selected images, or the current folder when nothing is selected, arranged as contact-sheet pages.

Page Setup selects the printer, paper and orientation. The controls in Print mode set image size, spacing and captions. Previous Print Page and Next Print Page move through a multi-page result.

Print > Print sends the preview to the printer. Save Contact Sheet writes the same layout to image files instead.
