ImageWalker 2.3 Metadata

Open an image and choose Image > Metadata... to inspect the information embedded in the loaded image. The command is unavailable until an image is ready. The dialog includes a preview and remembers the last tab used.

TabInformation
GeneralTitle, tags, description and image resolution. The resolution unit selector switches between pixels per inch and pixels per centimetre; it does not resize the image.
DetailsAuthorship, credit, copyright, category, creation date, location and other descriptive fields.
IPTCA read-only list of IPTC properties.
XMPA read-only list of XMP properties grouped by section.
EXIFCamera and exposure properties. Select a property to see its title and explanation where available.

Empty fields or lists mean that the image has no corresponding information that ImageWalker can display. The fields available depend on the file format and on the application or camera that wrote the image.

This is an information viewer, not a metadata editor. Closing the dialog does not change the image or write the file. Opening it alone does not enable Save.

For descriptions in the browser, thumbnail annotations and contact-sheet captions, see Descriptions and metadata. For image-saving capabilities, see Supported image formats.
