Options

Choose Tools > Options or press F6. The same dialog is used by ImageWalker 2.0, 2.2 and 2.3.

Thumbnails and columns

Set thumbnail width and height from 32 to 512 pixels. The annotation and detail-column lists choose which image properties are displayed and their order.

Pasted images

Choose the format used when an image is pasted or dropped into a folder. Format-specific controls, such as JPEG quality, appear below the format list.

Behaviour

Options control double-click full screen, subfolder walking, hidden files, metadata markers, descriptions in Detail view, thumbnail tooltips, Matrix view zoom, short dates, fades and EXIF auto-rotation.
